# Security

Security is a core priority of Nuvqix Protocol.

## Wallet Security

Nuvqix should remain non-custodial wherever wallet connectivity is used.

The application must never request or store:

- Seed phrases
- Private keys

## Application Security

Security measures include:

- Telegram authentication validation
- Independent blockchain transaction verification
- Supported token contract whitelisting
- Administrative endpoint protection
- Sensitive API rate limiting
- Security event logging

## Token Verification

The official NVQ contract must be verified before publication.

Token information should remain consistent across:

- Nuvqix Mini App
- Website
- Wallet metadata
- Blockchain explorers
- Official documentation

## Swap Security

The NVQ/USDT swap should only be activated after verification of:

- Official NVQ contract
- Liquidity pool
- Routing
- Slippage handling
- Transaction confirmation
- Security controls
