# NVQ Token

## Overview

NVQ is the ecosystem token of Nuvqix Protocol.

| Property | Value |
|---|---|
| Name | Nuvqix Protocol |
| Symbol | NVQ |
| Network | TON |
| Standard | TON Jetton |
| Total Supply | 100,000,000,000 NVQ |
| Decimals | 9 |

## Contract Address

**Status: Pending Official Verification**

Official NVQ Jetton master address will be published after the project team verifies the correct deployment.

> Do not treat an unverified contract address as the official NVQ token contract.

## Token Utility

NVQ is intended to support the evolving Nuvqix ecosystem, including future ecosystem utilities, community participation and planned swap infrastructure.

Specific utilities should only be described as active after they are technically deployed and publicly documented.

## Verification

Before interacting with NVQ, users should verify:

1. Official contract address
2. Token name
3. Token ticker
4. Decimals
5. Total supply
6. Official token metadata
7. Official Nuvqix communication channels
