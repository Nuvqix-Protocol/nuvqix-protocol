# Nuvqix Protocol
Powering the Next Digital Economy.

Nuvqix Protocol is a Telegram-first Web3 ecosystem built on the TON blockchain, designed to make blockchain participation more accessible through a familiar Telegram Mini App environment.

The initial product focuses on mining/points activities, tasks, referrals, community participation and wallet functionality.

## 🚀 Current Product

Nuvqix currently provides a Telegram Mini App experience featuring:

- Mine / Miners
- Tasks
- Friends & Referrals
- Wallet
- NVQ ecosystem token
- Community participation

The general swap functionality is currently disabled while market infrastructure is being prepared.

## 🔐 Security

Nuvqix is designed to prioritize secure and responsible Web3 interaction.

The application should never request or store:

- Seed phrases
- Private keys

Security priorities include:

- Telegram authentication validation
- Independent blockchain transaction verification
- Supported token contract whitelisting
- Administrative endpoint protection
- API rate limiting
- Security event logging
